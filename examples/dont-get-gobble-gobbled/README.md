# Example: Don't Get Gobble Gobbled (set up 2026-10-26)

The finished, game-specific starter documents for one real pitch, for depth and tone:
- `DESIGN.md`: the pitch verbatim, name check, early flags mapped to the Part A rules, interview questions and labelled suggestions.
- `PROJECT-CLAUDE.md`: the project rules (it becomes `CLAUDE.md` in the zip).
- `ART-CHECKLIST-project-section.md`: the project's art items.
- `KICKOFF-PROMPT.md`: the prompt Richard pasted into the game's new chat.

This example was made by hand, before `tools/make-starter.mjs` existed. The templates in `templates/docs/` follow the same structure.
